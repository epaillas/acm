# Example Notebooks

This directory contains example notebooks that demonstrate how to use the ACM package for various tasks. Each notebook is designed to showcase different features and functionalities of the library.

> [!NOTE]
> To prevent diffs for notebook executions, please only push changes to the cells in the repostory and no cell output. (Each new plot will push a high-quality image to the repo, which can easily bloat its size if not kept in check)
