# The unit test 

This folder contains the unit tests for the `acm` package. 
They are designed to check the validity of the functions and classes of the package.

The `acm/` folder contains the unit tests and reproduces the architecture of the `acm` package. Those tests are designed to be run without any installation, all dependencies are tested with mocks to only test package functionalities.

The `functional/` (?) folder contains black-box tests on the pipeline, run with an install to ensure the output is consistent

The `scripts/` folder contains tests for scripts, and are run manually when needed.
